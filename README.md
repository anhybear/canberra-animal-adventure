# Canberra Animal Adventure

A playful installable Three.js PWA for kids: choose a koala or jaguar, roam a stylized Canberra, collect respawning gumleaves, and discover landmarks.

## Run Locally

```bash
npm install
npm run dev
```

## Build And Test

```bash
npm run build
npx playwright test
```

## iPad

After GitHub Pages deploys, open the Pages URL in Safari on the iPad, then use Share -> Add to Home Screen.
